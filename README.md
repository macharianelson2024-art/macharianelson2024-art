## 🚀 Featured Project: Gmarketfy

Gmarketfy is a Kenyan multi-vendor marketplace built around a complete commerce loop:

- Clients browse products, place multi-item orders, pay with M-Pesa, and track deliveries.
- Vendors manage products, orders, drivers, subscriptions, analytics, wallets, and payouts.
- Drivers receive deliveries, broadcast live GPS, follow road routes, upload delivery proof, and complete orders.

The core design rule is simple:

> **Django owns the money. Firebase owns product data. Daraja moves the cash.**

The project has helped me practice payment callback idempotency, append-only financial records, one-way payment-state synchronization, GPS throttling, route rendering, and user-focused status handling.
